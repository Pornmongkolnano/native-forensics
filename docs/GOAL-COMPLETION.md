## Delivery evidence policy

Record the exact source revision (or dirty-source graph), binary and fixture digests, parameters/caps, toolchain/host, independent expected results, process lifecycle and meaningful limitations. Preserve raw local receipts outside Git and publish only sanitized summaries. Synthetic provider tests, live provider responses, local previews and submitted requests are separate events.

The next version cannot close this audit merely by passing a smaller subset. Update individual rows only when their named acceptance evidence exists. External prerequisites stay visible while independent engineering proceeds. The goal stays active until the full required scope is satisfied or the documented repeated-blocker threshold is met.
